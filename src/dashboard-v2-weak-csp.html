// ⚠ 'unsafe-inline' explicitly allows ALL of:
//   - <script>...</script> inline blocks
//   - onerror="..." event handlers
//   - onload="..." event handlers
//   - javascript: href values
//
// This completely defeats CSP's XSS protection.
// The browser treats it as: "trust all inline code".
⚠ Why This Is Worse Than No CSP
A developer who adds this CSP believes they have XSS protection. They don't. But now they may skip other mitigations (sanitization, HttpOnly cookies) because they assume the CSP is protecting them. This false confidence is the real danger of misconfigured CSP.
